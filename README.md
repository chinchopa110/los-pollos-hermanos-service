# Los Pollos Hermanos

Учебный проект сайта ресторанной сети Los Pollos Hermanos по веб-программированию. В репозитории собраны статическая версия сайта и серверное приложение с меню, отзывами, авторизацией и API.

Превью проекта - https://m3301-polyakov-backend.onrender.com/

## Структура репозитория

| Каталог | Содержимое |
| --- | --- |
| [m3301-polyakov-front](m3301-polyakov-front/) | Статический сайт на HTML, CSS и JavaScript: меню, новости, история, рестораны, контакты и отзывы. |
| [m3301-polyakov-backend](m3301-polyakov-backend/) | Приложение на NestJS и TypeScript с серверным рендерингом Handlebars, REST API и GraphQL. |

## Возможности серверного приложения

- Просмотр меню по категориям и управление позициями от имени администратора.
- Создание и редактирование отзывов с проверкой прав пользователя.
- Вход через сессии и разделение доступа администратора и клиента.
- REST API с документацией Swagger и GraphQL API.
- Журнал действий пользователей и загрузка изображений в S3-совместимое хранилище.

Меню, отзывы и журнал действий хранятся в памяти процесса: изменения сбрасываются после перезапуска. Для текущей реализации PostgreSQL не требуется.

## Запуск бэкенда

Приложение задеплоено на **Render** и доступно по адресу: [m3301-polyakov-backend.onrender.com](https://m3301-polyakov-backend.onrender.com/).

### Локальный запуск

Требуются **Node.js 22 или новее** и **npm**. Выполните из корня репозитория:

```bash
cd m3301-polyakov-backend
npm ci
npm run start:dev
```

После запуска доступны:

- Сайт: <http://localhost:3000>.
- Вход: <http://localhost:3000/login>.
- Swagger: <http://localhost:3000/api/docs>.
- GraphQL: <http://localhost:3000/graphql>.

Учебные учётные записи:

| Роль | Логин | Пароль |
| --- | --- | --- |
| Администратор | `admin` | `password` |
| Клиент | `client` | `client2024` |

Для запуска собранного приложения выполните в каталоге бэкенда:

```bash
npm run build
npm run start:prod
```

### Настройки окружения

При необходимости создайте файл `m3301-polyakov-backend/.env`. Для базового запуска он не нужен; загрузка изображений требует настроенного S3-хранилища.

| Переменная | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `PORT` | Порт приложения | `3000` |
| `NODE_ENV` | Режим работы; `production` отключает запись GraphQL-схемы в файл | — |
| `S3_ENDPOINT` | Адрес S3-совместимого хранилища | `https://storage.yandexcloud.net` |
| `S3_REGION` | Регион хранилища | `ru-central1` |
| `S3_BUCKET` | Имя бакета | `los-pollos-hermanos` |
| `S3_ACCESS_KEY_ID` | Идентификатор ключа доступа | — |
| `S3_SECRET_ACCESS_KEY` | Секретный ключ доступа | — |

Файлы `.env` исключены из Git; ключи доступа задаются локально или в окружении сервера.
